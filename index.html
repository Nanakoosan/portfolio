About Me

Nanako Shimizu


Summary

日本の自動車部品メーカーで、ソフトウェア開発のPM補佐として働いていました。プロたちが集まって一つのものを作り上げる「チームで進む感」が大好きでした。 働いているうちに「プロジェクトマネージャー」として人を率いるよりも、デザインの力で何かを生み出すことに惹かれていきました。

「英語を話したい」「海外で生活したい」「デザインも学びたい」そんな複数の衝動に正直に従ってみた結果、カナダに留学することを決めました。多様性あふれる街での生活は、スキル以上に「生きる力」と「何事も前向きに捉える精神」を鍛えてくれました。

PM補佐で培った「調整力」と、カナダで鍛えた「適応力」をベースに、デザインとコードを地続きに捉えた制作を心がけています。

サマリー

会社の信頼性を高め、初めて訪れる人にも安心感を持ってもらうことを目的に制作したWebサイト。事業内容が直感的に伝わる構成と、地域に寄り添った温かいトーンを意識しました。

担当範囲

デザイン、Webflow実装、CMS構築（ブログ）、ロゴ制作、レスポンシブ対応

使用ツール

Visual Studio Code / Lottie Animation

ターゲット

30〜60代の家・土地の売買をご検討中の方。

石川県内にお住まいの方。

課題

ホームページが存在せず、会社としての信頼性や事業内容が十分に伝わっていなかった。

また、ブログやニュースなどの発信の場がなく、事業が稼働していることをユーザーに伝えづらい状態だった。

サマリー

節電・遮熱効果を持つ窓用ガラスコート剤「LARTH」の製品紹介LP。認知拡大と、計測器を用いた「体感予約」への誘導を目的としています。 製品の持つ高い技術力や節電メリットを、専門的になりすぎず、一般の利用者や店舗オーナーが自分事として捉えられるような「親しみやすさ」と「安心感」を両立させたデザインを目指しました。

担当範囲

ディレクション、デザイン、STUDIO実装、グラフ含む素材制作、レスポンシブ対応

使用ツール

STUDIO / Figma / Illustrator

ターゲット

築15〜20年ほどの「単層ガラス（1枚ガラス）」の家に住んでいる、40歳以上の持ち家オーナー様、新築（複層ガラスが標準）ではなく、断熱・遮熱の悩みが出やすいリフォーム検討層

課題

「窓に塗る」という新概念を伝えるため、専門用語を避け、PASTORフォーミュラに基づいた「共感→解決→ベネフィット」のストーリーで構成。 施工への不安を払拭するため、実際の口コミや、数値を伴う図解を配置し、信頼感を醸成。

工夫した点

清潔感のあるブルーと、暮らしの温かみを感じさせる写真を組み合わせることで、工業製品特有の「冷たさ」を排除し、一般家庭や店舗でも導入しやすいクリーンなイメージを構築しました。

「夏は遮熱、冬は断熱」といった複雑な仕組みを、一目で理解できるようアイコンや図解を効果的に配置。専門用語を避け、ベネフィット（電気代削減、UVカット等）を強調するレイアウトにしました。

制作期間

1.5ヶ月

サマリー

自身のスキルや経験、「人となり」を多角的に伝えるためのポートフォリオサイトです。自分自身の世界観に「引き込む（Pull you in）」体験をデザインし、1つの作品として構築しました。

担当範囲

企画、デザイン、コーディング、イラスト制作、レスポンシブ対応

使用ツール

Visual Studio Code / Photoshop / Procreate

ターゲット

採用ご担当者様

課題

Webデザイン未経験からの転身にあたり、技術的なスキルだけでなく「信頼感」と「独自の強み」をどう両立させるかが課題でした。

工夫した点

自身の趣味である「本」をデザインのコンセプトに据えました。中央のメインコンテンツのみをスクロールさせる構成は、「本を読み進めるような体験」を意図しています。

画一的なテンプレート感を取り除き、スクロールするたびに発見があるレイアウトを目指しました。

制作期間

2ヶ月
